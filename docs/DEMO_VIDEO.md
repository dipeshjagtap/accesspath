# Backup demo video checklist

Record a 2–3 minute screen capture as a backup if the live deploy fails.

## Before recording

```bash
npm run demo:reset
npm run dev
```

Use region **Pune, Maharashtra (demo)**. Avoid real personal data.

## Script

1. Landing page — read tagline and “does not diagnose”
2. Intake — enter practical needs for a caregiver scenario
3. Review summary — edit one phrase, confirm
4. Plan — point to verified resources, unknowns, checklist
5. Open one resource detail — source + verification badge
6. Request referral — explicit consent checkboxes
7. Partner dashboard — change status to “assessment scheduled”
8. Close on business model: organizations pay for coordination

## Tips

- Zoom browser to 110–125% for readability
- Prefer quiet narration or on-screen captions
- Keep total runtime ≤ 3 minutes
- Export MP4 and store outside git (do not commit large binaries)

## What this repo cannot do automatically

Video capture requires your local screen recorder (OBS, QuickTime, etc.).
This checklist is the Phase 4 deliverable for the “backup demo video” item.
